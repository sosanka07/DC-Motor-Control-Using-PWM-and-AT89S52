
# PWM Controlled DC Motor using AT89S52

## Overview
This project demonstrates DC motor speed control using PWM (Pulse Width Modulation) generated through the AT89S52 microcontroller.

## Features
- PWM-based speed variation
- Efficient motor control
- Adjustable duty cycle
- Embedded C programming

## Components Used
- AT89S52 Microcontroller
- DC Motor
- L293D Motor Driver
- Crystal Oscillator
- Capacitors
- Power Supply

## Working Principle
The AT89S52 generates PWM signals by controlling ON and OFF timing through software delays/timers. The PWM signal is applied to the motor driver to vary motor speed.
